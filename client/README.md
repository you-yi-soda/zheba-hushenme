# 这把胡什么 v1.1.0 预览工程

2026-11-10。原生微信小程序，无需 npm 构建。此目录可直接在微信开发者工具中导入，`miniprogramRoot` 已配置。

已实现：品牌名称统一、新筒子牌面、首页页底使用说明与开源入口、玩法选择、默认七对、删除按钮边框、移除首页撤销、好友及朋友圈封面、微信原生复制链接参数、选牌草稿/撤回/确认、识牌后自动核对、有限重试与可读提示。

本公开模板已移除运营AppID及云环境。请填自己的AppID、云环境及服务名，不要把密钥放进客户端。继续连接已有的识牌服务，无需为本次客户端更新重新部署服务器。头像暂沿用经确认的绿底“胡”字示意，后台头像原图尚未取得。

导入此目录后先“编译”，再“预览”扫码。请按随包《预览与验收步骤.md》验证，尚未代替真机验收或正式发布。复制链接和朋友圈入口以当前微信客户端、账号及发布状态为准；本工程不伪造链接，也不把GitHub地址作为小程序分享链接。

识牌会上传照片，并在整个处理结束后尝试删除；照片不用于本轮训练。模型与算牌引擎沿用原版本，本次主要改善界面、核对与异常处理。1.1对应源码随本目录提供，微信上传与正式发布状态另行记录。

本地测试：`npm test`。另可用 `node tests/real-response.test.cjs 响应.json` 验证保存的真实识牌响应。规则引擎、页面流程和云调用均有本地测试，真机分享及真实冷启动仍需要手机验证。
